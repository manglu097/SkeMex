01The method

Memory that learns
what to keep.

Raw trajectories contain both useful procedures and noise. SkeMex distills experience into structured skills, estimates their context-dependent utility, and keeps the repository healthy over time.

01

Value-aware retrieval

Retrieve skills using semantic relevance, learned utility, and memory strength — so the agent sees experience that is useful for the current clinical context.

similarityutilitymemory strength

02What the paper shows

Structure turns experience
into transfer.

A

Skills over traces

Trajectory → reusable procedure

Trajectory-to-skill distillation compresses recurring procedures into branch-aware memory that can be recalled across related clinical contexts.

B

Utility guides reuse

Outcome → context-dependent value

Feedback estimates which memories help in context, guiding retrieval and repository decisions instead of treating every stored trace equally.

C

Closed-loop evolution

Review → promotion, merge, removal

Selective buffering, draft review, promotion, merging, and removal keep the skill repository compact and safer to reuse.
