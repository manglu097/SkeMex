01 · The idea

A memory that learns
what to remember.

Raw traces are noisy. SkeMex distills interaction experience into compact skills, scores their context-dependent utility, and keeps the repository healthy over time.

01

Value-aware retrieval

Retrieve skills using semantic relevance, learned utility, and memory strength — so the agent sees experience that is useful for the current clinical context.

similarityutilitymemory strength

02 · What the paper shows

Structure turns experience
into transfer.

Skills over traces

Trajectory-to-skill distillation compresses recurring procedures into reusable, branch-aware memory.

A

Utility guides reuse

Outcome feedback estimates which memories help in context, guiding both retrieval and repository governance.

B

Closed-loop evolution

Selective buffering, draft review, promotion, merging, and removal keep experience compact and safer to reuse.
